# Assessment Checklist — CIE + SEE

This repository is organized to support the supplied **DevOps – Evaluation Metrics & Assessment Scheme**. It is a sample portfolio; verify that these are the exact exercises prescribed by your instructor before submission.

## Rubric mapping (20 marks practical rubric)
- **Correctness & completion (8):** run each exercise and record the actual result in `EVIDENCE.md`.
- **DevOps tool/workflow usage (4):** use the tool-specific commands in each exercise README.
- **Troubleshooting & problem solving (4):** record one real issue and its fix per exercise, if encountered. Do not invent test results.
- **Repository/configuration discipline (2):** keep numbered folders, configuration, README files, and meaningful commits.
- **Output verification (2):** run the listed verification command and attach genuine screenshots/output if requested.

## Repository marks — 10 for CIE and 10 for SEE
- [ ] Every prescribed exercise is present in the designated repository.
- [ ] Each exercise is committed separately or in clearly meaningful commits.
- [ ] Repository updates are made within 7 days of the relevant lab session (maximum buffer stated in the scheme: 10 days).
- [ ] Repository is accessible to the evaluator and contains the latest working version.
- [ ] No passwords, tokens, private keys, or unrelated files are committed.

> Git history and commit dates may be evaluated automatically. Do not fabricate historical dates or claim work was completed earlier than it was.

## Practical + viva preparation
CIE and SEE each allocate 20 marks to practical execution, 15 to viva, and 5 to lab execution/explanation. Be ready to independently run the commands, explain the workflow and configuration, justify decisions, verify outputs, and troubleshoot errors.
